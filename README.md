# 자유 주제: 냉장고 파먹기 레벨업 챌린지 (음식 퀘스트 자동화)
게임 속 "상태창이 퀘스트를 내려주고, 완료하면 레벨업하며 새로운 스킬이 열리는" 구조를 요리 챌린지에 적용한 자동화. 참가자는 매주 요리 미션을 인증하고, 자동화가 통과 여부를 확인해 다음 미션을 자동으로 안내한다.

--- 
## 1. 반복 업무 정의
온라인/오프라인 요리 챌린지 운영 시, 참가자가 미션 인증샷을 제출할 때마다 운영자가 직접 확인하고 다음 미션을 개별 안내하는 작업이 반복된다. 참가자가 많아질수록 확인·안내 지연이 발생하고, 다음 미션 안내를 놓치면 참가자 이탈로 이어진다.

--- 
## 2. 도구 선정 및 선정 이유
선정 도구: Make

레벨별 통과/미통과 분기(Router)를 시각적으로 구성하기 쉬움
Google Forms(미션 인증) + Google Sheets(레벨 현황) + Gmail/카카오톡 연동을 무료 플랜 범위에서 처리 가능
보너스 과제인 AI 연동 Action(제출 사진/설명을 AI가 요약해 갤러리 소개 문구 자동 생성)도 쉽게 추가 가능

--- 
## 3. 레벨(퀘스트) 구성

> **Lv.1 초보 요리사**
> - 미션 내용 : 냉장고 속 재료 3가지로 요리 1개 완성
> - 인증 방법 : 사진+재료목록 Form 제출

> **Lv.2 살림 9단**
> - 미션 내용 : 자취요리(라면/볶음밥 등)를 나만의 방식으로 업그레이드
> - 인증 방법 : 사진+한줄설명 Form 제출

> **Lv.3 집밥 마스터**
> - 미션 내용 : 메인요리 + 반찬 2개 이상으로 한 상 차리기
> - 인증 방법 : 사진(전체 상차림) Form 제출

> **Lv.4 창작 셰프**
> - 미션 내용 : 기존 레시피를 응용한 나만의 창작 요리
> - 인증 방법 : 사진+레시피 설명 Form 제출

> **Lv.5 전설의 요리사**
> - 미션 내용 : "인생 한 끼" — 가장 자신 있는 요리로 마무리
> - 인증 방법 : 사진+소감 Form 제출

> **최종 리워드**
> 5레벨 전체 완료 시 칭호 인증서 자동 발급
> 시트에서 전체완료여부 = "완료"

--- 
## 4. 워크플로우 흐름
`Trigger` — 참가 신청 Form 제출 감지

`Action` — 웰컴 메시지 + Lv.1 미션(상태창 스타일 안내) 자동 발송, "레벨업트래커" 시트에 신규 행 생성

`Trigger(반복)` — 레벨별 미션 인증 Form 제출 감지 (제출 시 "레벨번호" 필드 포함)

`Filter` — 인증샷 첨부 여부 확인 (사진 URL이 비어있지 않은지)
- 미첨부 → 재제출 요청 메시지 발송 후 종료
- 첨부됨 → 다음 단계 진행

`Router` — 제출된 레벨 번호에 따라 분기
- Lv.1 통과 → 트래커에 Lv1 = Y 기록 → "레벨업!" 메시지 + Lv.2 미션 발송
- Lv.2 통과 → Lv2 = Y 기록 → Lv.3 미션 발송
- Lv.3 통과 → Lv3 = Y 기록 → Lv.4 미션 발송
- Lv.4 통과 → Lv4 = Y 기록 → Lv.5 미션 발송
- Lv.5 통과 → Lv5 = Y 기록 → 전체완료 체크로 이동
- Filter — 전체완료여부(Lv1~Lv5 모두 Y) 확인

`Action` — 조건 충족 시 "전설의 요리사" 인증서 자동 발급 + 축하 메시지, 인증서발급여부 = Y 기록

`(보너스) AI 연동 Action` — 제출된 사진 설명을 생성형 AI로 요약해 참가자 갤러리용 소개 문구 자동 생성

`예외 처리(리마인드)` — 미션 안내 후 5일간 제출이 없으면 리마인드 메시지 자동 발송 (보너스 과제: 재시도 전략)

--- 
## 5. 검증 방법
- 테스트 참가자로 Lv.1~5를 순서대로 인증하며 각 레벨업 메시지가 정상 발송되는지 확인
- 사진 미첨부 케이스로 재제출 요청 분기가 정상 작동하는지 확인
- 전체 완료 후 인증서가 중복 발급되지 않는지 확인
- Make 실행 히스토리에서 Router의 각 레벨 분기 경로가 최소 1회 이상 실행된 로그 캡처

--- 
## 6. 기대 효과
- 참가자가 게임처럼 레벨업하며 몰입감 있게 챌린지에 참여
- 운영자의 반복적인 확인·안내 부담 감소
- 레벨별 이탈률 데이터를 통해 어느 미션이 어려운지 파악 가능

--- 
## 7. 도구 비교분석 — 음식 퀘스트 자동화에 어떤 도구가 적합할까

| 비교 항목 | Make | Zapier | n8n |
|---|---|---|---|
| UI/UX | 시각적 노드 기반, 5단계 레벨 분기를 한 화면에서 파악하기 좋음 | 리스트 기반, 직관적이지만 복잡한 분기는 화면이 길어짐 | 노드 기반, Make와 유사하나 진입장벽 높음 |
| 조건 분기 난이도 | Router로 다중 분기 무료 플랜에서도 구성 가능 | Filter는 무료, 다중 경로(Paths)는 유료 플랜 필요 | 자유도 높지만 직접 로직 구성 필요 |
| 사진/파일 업로드 처리 | Google Forms 응답의 파일 URL을 그대로 활용하기 쉬움 | 동일하게 가능하나 파일 관련 모듈이 다소 제한적 | 가능하나 설정 복잡 |
| 무료 플랜 범위 | 월 1,000 Ops — 소규모 챌린지(참가자 수십 명)엔 충분 | 월 100 Tasks — 레벨 5단계 × 참가자 수가 많으면 금방 소진 | 셀프호스팅 시 무제한(단, 서버 운영 필요) |
| AI 연동(보너스 과제) | OpenAI/Claude 모듈 기본 제공, 연결 쉬움 | Zapier도 AI 앱 연동 있으나 무료 플랜에서 제한적 | API 직접 호출 필요(자유도는 가장 높음) |
| 실행 로그 확인 | History에서 각 모듈 입출력 데이터 확인 가능 | Task History 제공, 상세도는 Make보다 단순 | 로그 직접 관리해야 함(자기 서버) |
| 초기 진입장벽 | 중간 — 회원가입만으로 바로 시작 | 낮음 — 가장 쉬움 | 높음 — 설치/호스팅 필요 |

**결론: Make 추천.** 5단계 레벨 분기가 핵심인 이 챌린지는 무료 플랜에서도 다중 Router 분기가 가능한 Make가 가장 적합하다. 다만 과제는 도구 2개 이상 비교가 필수이므로, **프로젝트 1(도구 비교)엔 Make + Zapier 조합**을 추천한다 — Zapier는 무료 플랜에서 분기가 제한적이라는 점 자체가 좋은 비교 포인트가 된다. n8n은 학습 곡선이 있어 이번 과제보다는 확장 학습용으로 언급만 해두는 것이 좋다.

## 8. 업무 순서 (냉장고 파먹기 레벨업 챌린지 자동화)

**1단계 — 콘텐츠 및 데이터 구조 준비**

- [ ] 레벨 1~5 미션 내용, 통과 기준(사진 필수 여부 등) 확정
- [ ] Google Sheets에 "[레벨업트래커](https://docs.google.com/spreadsheets/d/1-80lPgTNkbIg3CZkRVtp_WkyCOR0O52YI3coC7pH1QU/edit?usp=drive_link)" 탭 업로드 (제가 드린 xlsx 그대로 사용)
- [ ] [참가 신청 폼](https://docs.google.com/spreadsheets/d/1-80lPgTNkbIg3CZkRVtp_WkyCOR0O52YI3coC7pH1QU/edit?usp=drive_link) + [레벨별 미션 인증 폼](https://docs.google.com/forms/d/e/1FAIpQLSfIZjsnyKoXfJ-SDrj-mtCZUSrJrplve5__WZ5dVrzfRTyzXA/viewform?usp=publish-editor) (레벨번호 필드 포함) 제작


**2단계 — Trigger 설정**

- [ ] Make에서 참가 신청 Form 제출 Trigger 연결
- [ ] 미션 인증 Form 제출 Trigger 별도 시나리오로 연결

**3단계 — 조건 분기(Filter/Router) 설계**

- [ ] Filter: 인증샷 URL 첨부 여부 확인 (미첨부 시 재제출 요청 경로)
- [ ] Router: 제출된 레벨번호(1~5)에 따라 5개 경로 분기
- [ ] 각 경로별 "레벨업 메시지 + 다음 미션 안내" 문구 준비

**4단계 — Action 연결**

- [ ] Gmail/카카오톡 발송 모듈 연결
- [ ] Google Sheets Update Row로 해당 레벨 컬럼 Y 갱신
- [ ] (보너스) OpenAI/Claude 모듈로 제출 사진 설명 요약 → 갤러리 소개 문구 자동 생성

**5단계 — 최종 완료 처리**

- [ ] Filter: 전체완료여부 = "완료" 확인
- [ ] Action: "전설의 요리사" 인증서 자동 발급 + 축하 메시지
- [ ] 인증서발급여부 Y 갱신 (중복 발급 방지)

**6단계 — 테스트 & 검증**

- [ ] 테스트 참가자로 Lv.1~5 순서대로 인증 제출, 각 레벨업 메시지 정상 발송 확인
- [ ] 사진 미첨부 케이스로 재제출 요청 분기 테스트
- [ ] Make History에서 각 레벨 Router 분기 경로가 1회 이상 실행된 로그 캡처

**7단계 — 예외 처리 및 보완**

- [ ] 미션 안내 후 5일간 미제출 시 리마인드 메시지 자동 발송 설계
- [ ] 발송 실패(연락처 오류 등) 시 관리자 알림 경로 추가

**8단계 — 프로젝트 1(도구 비교) 구현**

- [ ] 동일한 워크플로우(참가 신청 → 조건분기 → 알림+기록)를 Zapier에도 구현
- [ ] 두 도구의 구성 화면, 실행 결과 화면 각각 캡처
- [ ] 비교 분석 보고서 작성 (위 표의 7개 항목 활용 가능)
